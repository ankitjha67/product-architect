# Brand & Messaging Framework

Messaging is not copywriting — it's the strategic decision about what you mean to
customers and why they should choose you. This framework gives you the positioning
statement, Dunford's positioning process, the messaging house, the persona-message
matrix, voice & tone, the strategic narrative, naming, and the precise definitions
of value prop vs tagline vs pitch vs boilerplate — all as copy-paste templates.

---

## 1. THE POSITIONING STATEMENT

```
TEMPLATE:
  For [target customer]
  who [need / opportunity],
  [product name] is a [market category]
  that [key benefit / reason to buy].
  Unlike [primary competitive alternative],
  we [primary differentiator].

WORKED EXAMPLE (a project tool for design teams):
  For design teams at fast-growing startups
  who lose hours reconciling feedback scattered across Slack, email, and files,
  Inkwell is a design-review platform
  that turns every comment into a tracked, resolvable task in one place.
  Unlike general project tools like Asana,
  we're built around the design file itself, so feedback lives where the work is.

RULES:
  ✓ ONE target, not "everyone." ✓ A category they already understand & search for.
  ✓ A differentiator they can VERIFY, not a subjective claim ("better UX").
  ✓ The competitive alternative is the STATUS QUO (often a spreadsheet/email),
    not just the obvious rival.
```

### April Dunford's positioning process (the rigorous version)
```
Positioning is the CONTEXT you set so customers instantly "get" your value.
Work these in order:

1. COMPETITIVE ALTERNATIVES — what would customers use if you didn't exist?
   (Often "a spreadsheet" or "nothing/manual," not a named competitor.)
2. UNIQUE ATTRIBUTES — what do you have that the alternatives don't? (features,
   capabilities, model, data, relationships)
3. VALUE — what those attributes ENABLE for the customer (map attribute → benefit).
4. WHO CARES MOST — the customers for whom that value is most acute (your best-fit
   segment). Their characteristics define your target.
5. MARKET CATEGORY — the frame of reference that makes your value obvious. Choosing
   the category is a strategic act (it sets expectations & competitors).
6. (Optional) RELEVANT TREND — a "why now" trend that makes you timely without
   overwhelming the positioning.

KEY INSIGHT: don't start from "what is my product?" Start from "what's the best
context to make my strongest value obvious to the people who care most?"
```

## 2. THE MESSAGING HOUSE (hierarchy)

```
                  ┌───────────────────────────────────┐
                  │   VALUE PROPOSITION (the roof)     │
                  │   one line: the core promise       │
                  └───────────────────────────────────┘
        ┌──────────────────┬──────────────────┬──────────────────┐
        │  PILLAR 1         │  PILLAR 2         │  PILLAR 3        │
        │  (key benefit)    │  (key benefit)    │  (key benefit)  │
        ├──────────────────┼──────────────────┼──────────────────┤
        │ proof point       │ proof point       │ proof point     │
        │ proof point       │ proof point       │ proof point     │
        │ feature           │ feature           │ feature         │
        └──────────────────┴──────────────────┴──────────────────┘
                       FOUNDATION: positioning + audience

TEMPLATE:
  VALUE PROP:  "____________________________________" (the one-liner)
  PILLAR 1: ________  → proofs: ______, ______  → features: ______
  PILLAR 2: ________  → proofs: ______, ______  → features: ______
  PILLAR 3: ________  → proofs: ______, ______  → features: ______

RULE: features ladder UP to benefits, benefits ladder up to the value prop.
Lead with the roof (benefit), support with the floor (features). Most teams do
the reverse and bury the value under a feature list.
```

## 3. PERSONA-BY-MESSAGE MATRIX

```
Different buyers care about different things. Same product, tailored message.

| Persona          | Their priority         | Message angle                  | Proof          |
|------------------|------------------------|--------------------------------|----------------|
| Economic buyer   | ROI, risk              | "Cut review cycles 40%"        | ROI calc, case |
| Champion/user    | Daily pain relief      | "Feedback in one place"        | demo, free trial|
| Technical evaluator| Security, integration| "SOC2, API, SSO"               | docs, compliance|
| Skeptic/blocker  | Switching risk         | "Migrate in a day, no lock-in" | migration guide|

Fill one row per persona. Each gets a different headline, proof, and CTA — but
all ladder to the SAME positioning. Consistency in meaning, variety in emphasis.
```

## 4. VOICE & TONE GUIDE

```
VOICE = your consistent personality (stable). TONE = how it flexes by context
(an error message vs a celebration differ in tone, same voice).

WE ARE ___, NOT ___:
  We are confident,   not arrogant.
  We are clear,       not dumbed-down.
  We are warm,        not cutesy.
  We are direct,      not blunt.
  We are expert,      not jargon-y.

DO / DON'T (make it concrete with examples):
  DO:    "Your file's ready. Here's what changed."
  DON'T: "Operation completed successfully. The system has processed your request."

  DO:    "That didn't work. Try again or contact us — we'll fix it fast."
  DON'T: "Error 0x004: An unexpected exception occurred."

TONE BY CONTEXT:
  | Context        | Tone                                   |
  |----------------|----------------------------------------|
  | Onboarding     | encouraging, guiding                   |
  | Error/failure  | calm, accountable, helpful             |
  | Success moment | celebratory, brief                     |
  | Billing/legal  | precise, transparent, no surprises     |
  | Marketing      | confident, benefit-led                 |
```

## 5. THE STRATEGIC NARRATIVE ("Why Now")

```
A strategic narrative isn't about your product — it's about a SHIFT in the world
that makes your product inevitable. (The "why now" that great categories ride.)

STRUCTURE:
  1. NAME THE SHIFT — a change in the world (tech, behavior, regulation, economics).
     "The way teams work has gone fully async and distributed."
  2. STAKES — winners and losers of this shift. Create urgency, not fear.
     "Teams still relying on real-time, in-person rituals are falling behind."
  3. PROMISED LAND — the better future for those who adapt (aspirational, not your feature list).
     "Imagine feedback that's captured, tracked, and resolved without a single meeting."
  4. OBSTACLES — why it's hard to reach that future today.
  5. YOUR PRODUCT AS THE BRIDGE — you, as the way to cross to the promised land.

USE IT FOR: keynotes, fundraising, vision decks, category creation. The narrative
sits ABOVE the messaging house — it's the worldview; the house is the pitch.
```

## 6. NAMING FRAMEWORK

```
NAME TYPES:
  | Type          | Example         | Pros                  | Cons               |
  |---------------|-----------------|-----------------------|--------------------|
  | Descriptive   | Salesforce      | instantly clear       | generic, hard to own|
  | Suggestive    | Stripe, Slack   | evocative, ownable    | needs explaining   |
  | Invented      | Spotify, Kodak  | unique, trademarkable | meaningless at first|
  | Real-word     | Apple, Amazon   | memorable             | crowded, costly    |
  | Compound      | Facebook, Snowflake| descriptive+ownable| can feel literal   |

EVALUATION CHECKLIST (score each candidate):
  ☐ Easy to say & spell (the "radio test" — say it aloud, no spelling needed)
  ☐ Memorable & distinct in the category
  ☐ .com (or acceptable domain) and handles available
  ☐ Trademark-clear in your classes & geographies (⚠ legal check — see disclaimer)
  ☐ No negative meaning in target languages
  ☐ Room to grow (won't box you into one product/market)
```

## 7. MESSAGE TESTING METHODS

```
| Method                | What it tells you                    | When               |
|-----------------------|--------------------------------------|--------------------|
| 5-second test         | What's the value? (recall after 5s)  | landing-page clarity|
| Message-market fit survey| which message resonates (rank/choose)| pre-launch         |
| Ad/headline A/B test  | which message converts (real behavior)| live traffic       |
| Sales-call mining     | which words prospects use & react to | always             |
| "Most disappointed" test| how much they'd miss you (PMF signal)| product-message fit|
| Comprehension interviews| do they understand the category/claim| positioning checks |

GOLDEN RULE: customers' WORDS > your words. Mine reviews, support tickets, and
call transcripts for the language they already use, then mirror it.
```

## 8. TAGLINE vs VALUE PROP vs PITCH vs BOILERPLATE

```
| Asset           | Purpose                          | Length    | Example                          |
|-----------------|----------------------------------|-----------|----------------------------------|
| TAGLINE         | Brand emotion/memory hook        | 2-6 words | "Just Do It." / "Think Different."|
| VALUE PROP      | The concrete promise/benefit     | 1 sentence| "Send money to anyone, instantly, free."|
| ELEVATOR PITCH  | Quick what+who+why (verbal)      | 1-3 sent. | "We help design teams turn scattered feedback into tracked tasks, so reviews take hours not weeks."|
| BOILERPLATE     | Standard "about" for PR/footer   | 2-4 sent. | "Inkwell is the design-review platform for modern teams. Founded in 2024, it's used by 500+ companies to..."|

KEY DISTINCTION:
  TAGLINE = feeling (brand).  VALUE PROP = benefit (clarity).
  They are NOT the same. "Just Do It" is a tagline, not Nike's value prop.
  A tagline can be aspirational/emotional; a value prop must be concrete & specific.
```

## 9. MESSAGE CONSISTENCY ACROSS TOUCHPOINTS

```
The same core message, adapted (not reinvented) per surface:

| Touchpoint        | What leads here                           |
|-------------------|-------------------------------------------|
| Website hero      | value prop headline + primary CTA         |
| Ads               | one pillar + proof, single CTA            |
| Sales deck        | narrative → positioning → pillars → proof |
| Product onboarding| the promised value, delivered (no jargon) |
| Email/lifecycle   | per-stage angle (see customer-journey.md) |
| Support/help docs | clear, on-voice, never contradicting promise|
| Social            | narrative + proof points, human tone      |

GOVERNANCE: maintain a single messaging source-of-truth (the house + voice guide).
Every surface references it. Inconsistency erodes trust — if the ad promises X and
onboarding delivers Y, you've created churn.
```

## 10. BRAND ARCHITECTURE

```
MASTERBRAND (branded house) — one strong brand spans products.
  Google → Gmail, Maps, Drive.  Apple → iPhone, iPad, Watch.
  ✓ Efficient, equity compounds. ✗ One scandal touches everything.

HOUSE OF BRANDS — independent brands, parent invisible.
  P&G → Tide, Gillette, Pampers.  Unilever → Dove, Axe.
  ✓ Segment/risk isolation. ✗ Expensive — each brand built from scratch.

ENDORSED — sub-brands with parent endorsement.
  "Marriott" → Courtyard by Marriott.  ✓ borrows trust + own identity.

SUB-BRAND — parent + product brand share billing.
  Google Pixel, PlayStation by Sony.

DECISION: branded house when products serve overlapping audiences & values align
(most startups — don't fragment early). House of brands when audiences/values
diverge or you need risk isolation. Default for a startup: masterbrand.
```
